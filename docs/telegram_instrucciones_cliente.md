# 📲 Instrucciones para vincular tu Telegram

Para recibir recordatorios y confirmar tus citas automáticamente, debes vincular tu cuenta de Telegram con nuestro sistema. Es muy sencillo:

## 1. Abre el bot
- Haz clic en este enlace: [Inicia el bot de Telegram](https://t.me/Charapita_bot)
- Se abrirá el chat con nuestro bot "BarberíaReservaBot".

## 2. Escribe el comando /start
- En el chat del bot, escribe: `/start`
- El bot responderá con un mensaje de bienvenida.
- En ese momento tu cuenta queda vinculada automáticamente.

## 3. Beneficios de vincular tu cuenta
- Recibirás recordatorios de tus citas directamente en Telegram.
- Podrás confirmar o cancelar citas con un solo clic.
- El administrador podrá contactarte más rápido si es necesario.

## 4. ¿Dónde encuentro mi username?
- Abre Telegram → Ajustes → Nombre de usuario.
- Si tienes un username (ejemplo: @alexanderac1), puedes ingresarlo en el formulario de reservas.
- Esto permite que el administrador te escriba directamente por Telegram.

⚠️ Nota: No necesitas saber tu ID numérico de Telegram. El sistema lo guarda automáticamente cuando usas /start.
